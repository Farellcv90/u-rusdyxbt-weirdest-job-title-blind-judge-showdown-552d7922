One job title, the weirdest one we could think of: **Head of Lost Umbrella Reunions** — a mundane institutional role ("Head of ...") with one absurdly specific duty: reuniting lost umbrellas with their owners. It sounds like a real department, it is instantly picturable, and the twist lands on the first read.

`main.py` validates the title (1–60 chars, no surrounding whitespace), encodes it as UTF-8, writes exactly those bytes to `/output/entry.txt` — nothing else, no trailing newline — and reads the file back to verify it is byte-identical.

## Run it

```sh
python3 main.py
```
